# 英国路线编排：范围、使用与数据边界

更新：2026-10-14。当前代码随本轮报告同步 GitHub，完整应用仍为本地预览。

## 怎么使用

1. 从 `/plan` 填写或跳过基础信息，进入 `/plan/route`。顶部需求助手可理解、补问并经采用后更新路线，也可直接编辑路线字段。
2. 从目录选择住宿据点，或展开“加入目录外的小城 / 小镇”，填写名称、所属地区和可选接驳据点。自定义地点不会被自动认证为英国地点。
3. 用上下按钮调整顺序，填写每站住宿晚数；离境日为抵达日加总住宿晚数。转场日不能当作完整游玩日。当前支持最多 12 站、60 晚，每站 1–30 晚，不提供自动最优排序。
4. 选择抵达与离境机场。当前目录为 LHR、MAN、EDI、BFS，其他机场在想法中备注并另行核对。填写的是英国落地/起飞时间，不是海外出发时间。跨夜航班以英国落地日开始路线。
5. 在每段交通选查询方向、打开官方入口，填写真实查询结果、日期和门到门耗时。国内航班/海渡需要包含两端地面接驳。北爱与大不列颠之间只提供海空方向，不能全程按火车或自驾处理。
6. 查看待核对事项，保存到当前浏览器；可导出 JSON 备份或文字清单。导入替换编辑区，只有再次保存才覆盖本地路线记录。

日期修改会清除交通记录及原航班号/时间；顺序、据点、住宿变化会清除交通记录，总晚数变化还会清除原离境航班号/时间。机场选择和出发/下一目的地文本保留。当前未提供路线版本历史，重大修改前建议导出备份。

## 已实现与未实现

已实现：英国四区25个目录条目（新增皮特洛赫里），目录外小镇输入，住宿据点排序、日期分配、机场查询、城际分段、跨海方式限制、未知耗时提示、保存恢复和备份验证。需求助手已通过两轮真实补问和轮廓确认测试；手动路线仍可独立编辑。

这些是由用户选择和本地规则计算的路线草案，不是模型生成、实际交通可行性认证或景点数据扩展。没有核实每个城市对之间的可达性，不承诺所选方式有直达。未知耗时不分配景点时间；手填 6 小时以上提示考虑转场日，阈值为产品提醒，不是交通事实。

原逐日 Agent 移到 `/plan/details`，旧 `/plan/example`、`/plan/generate`、`/plan/saved` 保持。原三城逐日资料、生成与编辑能力仍独立保留，新路线不会偷偷降级为三城或直接传给不支持新城市的模型。路线保存键 `slowtrail.uk-route.v1` 与原逐日保存分开。

尚未完成：全英国资料覆盖与最优路线推荐、新逐日 AI 的真实验收、航班与班次实时检索、价格/余票/预订、时区转换与实际接驳冲突核验、云同步。需求理解当前已有有限真实验证，但输入其他国家不会使其成为受支持规划目的地；自定义地名始终待核实。

## 官方查询来源

2026-10-12 实际查看下列页面；仅用于官方查询入口与服务范围，不把网页入口当作已取得班次数据。目录城市名称为编辑整理，未扩展景点知识库。

| 来源 | 本轮查看结果与用途 |
| --- | --- |
| [National Rail](https://www.nationalrail.co.uk/journey-planner/) | 页面提供起终站、日期时间的铁路查询。本站链接不自动传递查询条件，需在官网选择实际车站。 |
| [Traveline](https://www.traveline.info/) | 大不列颠巴士、铁路、电车、大巴、渡轮查询；用于小镇与机场末段接驳查询。 |
| [Translink](https://www.translink.co.uk/JourneyPlanner) | 北爱官方入口可读取页面壳，实际查询动态加载；本轮未执行外部班次搜索。 |
| [Stena Line](https://www.stenaline.co.uk/routes) | 航线页列出 Belfast–Cairnryan、Belfast–Liverpool 等；仅提供航线目录入口，不承诺任意城市间直达或指定日期有票。 |
| [Heathrow](https://www.heathrow.com/transport-and-directions) | 地面交通页可读取，有铁路、巴士、大巴、出租车等分类。 |
| [Manchester Airport](https://www.manchesterairport.co.uk/getting-to-and-from/) | 地面交通页可读取，链接进入机场的交通查询。 |
| [Edinburgh Airport](https://www.edinburghairport.com/transport-links) | 地面交通页可读取，提供巴士、电车、火车及其他分类和航班入口；不据此认定机场有直达铁路。 |
| [Belfast International](https://www.belfastairport.com/) | 本轮抓取 403，页面明确标注未能核对；提供官网及 Translink 替代查询入口。 |

## 实时接口预留

`src/lib/transport-provider.ts` 定义服务端 `TransportProvider` 的查询、结果、来源与抓取时间字段。当前实现只返回 `not_configured`，不发网络请求。`GET /api/transport` 返回同一明确状态；尚未实现接受查询参数的公开搜索接口。未配置不能解释为“没有班次”。没有新增密钥、订阅或模型调用。

下阶段应先补充英国目的地的有来源资料和路线可行性检查，再将确认的住宿路线接入逐日生成；实时供应商需要另外确认服务配置与费用。
