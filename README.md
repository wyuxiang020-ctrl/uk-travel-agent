# 英伦慢游 Slowtrail

面向中文使用者的英国旅行规划原型。先表达旅行想法，再确认城市与时间，通过地点故事和地图认识目的地，并查看带来源的参观资料。

当前支持伦敦、牛津、巴斯的 3–7 天示例行程。**这是 AI 旅行规划方向的产品原型，目前没有接入模型生成。** 本项目优先验证需求表达、信息阅读、地图点选和资料检查的完整体验。

## 可以体验什么

- 旅行首页：计划与发现双入口、三种旅行心情。
- 需求与确认：城市、日期、节奏、兴趣和特别安排；选填内容按需展开。
- 故事发现：六篇原创地点故事，城市筛选与重点地图标记。
- 示例工作区：逐日行程、地点详情和地图联动；调整入口只记录想法。
- 资料与检查：三城共 30 个有来源的地点、三对交通参考，以及结构化单日时间与固定活动冲突检查。

## 本地运行

使用 Node.js 24，安装后启动生产预览：

```sh
npm ci
npm run preview
```

打开 [本地预览](http://127.0.0.1:3005)。依赖已安装时不必重复 `npm ci`。开发时使用 `npm run dev`；开发与生产预览共用 3005，一次运行一种。

| 路由 | 页面 |
| --- | --- |
| `/` | 旅行首页 |
| `/discover` | 故事与重点地图 |
| `/plan` | 需求填写与确认 |
| `/plan/example` | 七天示例工作区 |
| `/explore` | 资料、交通与单日检查 |

地图底图需要网络访问；底图加载失败时，地点资料仍可阅读。GitHub 仓库用于分发代码与文档，完整应用需要支持 Node.js 的运行环境，不能把动态查询接口当作纯静态 GitHub Pages 运行。

## 数据与能力边界

地点资料是核对日期为 2026-10-09 的本地来源快照，不是实时搜索。地图位置近似；停留时间和转场缓冲包含编辑估算，不能当作导航、实时班次或整体可行性保证。

行程按城市、首尾和天数组合固定示例，可能重复地点。自然语言、兴趣、节奏和特别安排不会驱动真实生成；没有实际替换、锁定、撤销或本地保存恢复。刷新会清空当前会话。

单日检查接受明确填写的地点、钟面时间和固定活动，识别重叠、转场预留不足、已知闭馆及资料未知。未覆盖全部例外、余票、最后入场或同城移动。

## 代码结构

`src/app` 存放页面及接口，`src/components` 存放交互界面，`src/data` 存放地点、故事及交通资料，`src/lib` 存放需求与检查逻辑。使用 Next.js、TypeScript、Tailwind CSS 和 Leaflet。

模型接入、真实行程调整与保存恢复是后续计划，当前未实现。第三方照片及地图遵循各自许可和署名要求。
